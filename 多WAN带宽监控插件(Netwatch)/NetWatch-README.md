# NetWatch 多WAN实时带宽监控

OpenWrt / iStoreOS 安装与卸载说明（V1.0）

## 一、项目介绍

NetWatch 是一款轻量级多 WAN 网络带宽监控工具，采用独立 CGI
网页架构，并集成 LuCI
菜单入口。支持自动识别已配置的逻辑网络接口、多选监控、1s / 2s / 5s / 10s
刷新、实时上下行速率、动态趋势曲线、累计流量及分流占比。监控设置保存在当前浏览器，网页支持电脑和手机，无需第三方前端库。

## 二、文件与安装环境

- `install-Netwatch.sh`：一键安装及覆盖升级脚本。
- `uninstall-Netwatch.sh`：一键卸载脚本。
- OpenWrt / iStoreOS，已安装 LuCI、uhttpd，支持传统 Lua LuCI
  控制器，并具备 UCI、UBUS、awk 和 jshn.sh 等基础组件。
- 已开启 SSH 服务，并拥有 root 管理权限。

## 三、安装教程

**1. 上传脚本**：使用 【WinSCP】或 【MobaXterm】等工具，将
`install-Netwatch.sh` 上传至路由器 `/tmp/`
目录。建议采用二进制传输模式。

**2. 连接 SSH**：将示例 IP 替换为路由器实际管理地址。

``` sh
ssh root@192.168.1.1
```

**3. 执行安装命令**：

``` sh
cd /tmp
chmod +x install-Netwatch.sh
sh install-Netwatch.sh
```

脚本自动清理旧文件、生成 CGI 网页和数据接口、转换中文编码、创建 LuCI
菜单、清理缓存并重启 uhttpd。终端显示 `[OK] 部署完成`
即表示脚本执行完成。管理网页可能短暂断开，无需重启整个路由器。

## 四、访问监控页面

- LuCI 后台：**网络 → 多WAN带宽监控**。
- 直接访问：`http://192.168.1.1/cgi-bin/wan-bandwidth`（替换为实际 IP
  及协议）。

若菜单未显示或页面仍为旧版，按 Ctrl + F5 强制刷新，或重新登录后台。

## 五、使用说明

**网络接口**：在监控设置中勾选需要监控的逻辑接口，点击「应用设置」。首次采样需等待下一次刷新才能计算速率。未连接接口可在上线后监控。

**刷新间隔**：可选择 1 秒、2 秒（默认）、5 秒、10
秒，无需修改脚本或重启。接口和刷新设置保存在当前浏览器，下次访问自动恢复。

**累计流量**：累计 RX 是实际设备累计接收字节数，累计 TX
是累计发送字节数。计数从设备计数器建立或上次清零时开始，并非当天或打开网页后的流量。重启路由器、重建设备或计数器清零可能导致累计值重置；刷新或关闭网页不会清零。累计总流量为当前所选在线接口对应设备的
RX + TX，同一设备只统计一次。

保存为 UTF-8 无 BOM、Linux LF 格式，再重新执行安装即可生效。

## 六、版本升级

已安装旧版时，无需提前卸载。上传新版安装脚本至 `/tmp/`，执行：

``` sh
cd /tmp
sh install-Netwatch.sh
```

升级完成后按 Ctrl + F5 强制刷新页面。

## 七、卸载教程

**1. 上传脚本**：将 `uninstall-Netwatch.sh` 上传至路由器 `/tmp/` 目录。

**2. 执行卸载命令**：通过 SSH 登录后执行：

``` sh
cd /tmp
chmod +x uninstall-Netwatch.sh
sh uninstall-Netwatch.sh
```

脚本自动删除 CGI 网页、数据接口、LuCI
菜单控制器及旧版残留，清理缓存并重启 uhttpd。终端显示 `[OK] 卸载完成`
即表示脚本执行完成。

**3. 确认卸载**：重新登录 LuCI 或按 Ctrl +
F5，确认「网络」菜单下的「多WAN带宽监控」已消失。浏览器本地保存的监控设置不会自动删除，如需清理，请手动清除对应站点的存储数据。

## 九、常见问题与注意事项

- **中文乱码**：检查 UTF-8 无 BOM、LF
  换行及二进制传输。自动编码转换无法恢复已被编辑器替换为问号的字符。
- **菜单未显示**：强制刷新或重新登录，并确认固件支持传统 Lua LuCI
  控制器。
- **没有速率数据**：确认接口在线且有流量，等待下一次采样。
- **是否影响上网**：脚本不修改
  WAN、mwan3、路由或防火墙规则；安装和卸载会短暂重启
  uhttpd，无需重启路由器。
- **临时文件**：`/tmp/`
  中的脚本可能在路由器重启后丢失，已安装到系统中的文件通常不受影响。
- **统计口径**：避免同时选择同一流量路径上的多个设备，以免重复统计。
- **安全提醒**：独立 CGI
  页面及数据接口没有独立身份验证，仅在可信内网使用，不要直接暴露到公网。
- **兼容性**：不同固件版本的 LuCI 架构存在差异，不能保证所有 OpenWrt
  版本均可使用。
